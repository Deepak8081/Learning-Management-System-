An enterprise-ready **Learning Management System (LMS)** designed for digital course delivery, student enrollment, instructor course creation, lecture streaming, and progress tracking built with the **MERN Stack**.

---

## ✨ Features
- **Student Portal**: Course browsing, keyword search, enrollment, curriculum overview, and lecture video player.
- **Instructor Portal**: Course creation studio, video upload, lesson structuring, and student enrollment metrics.
- **Progress Tracking**: Real-time course completion percentages and milestone badges.
- **Authentication & RBAC**: Granular permissions distinguishing Students and Instructors via JWT authentication.
- **Responsive Web UI**: Built for seamless viewing across smartphones, tablets, and laptops.

---

## 📂 Architecture
```
Learning-Management-System-/
├── client/                     # React Single Page Application
└── server/                     # Express & MongoDB backend API
```

---

## 🚀 Quick Start
```bash
# Backend
cd server && npm install && npm start

# Frontend
cd ../client && npm install && npm run dev
```
